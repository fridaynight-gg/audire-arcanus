# Docs

Canonical project memory for the rewrite. Read in this order at session start:

1. `AGENT-CONTRACT.md` — agent contract (short). Root `/AGENTS.md` is still the Nest text until write approval.
2. `LOCK.md` — frozen decisions
3. `RITUAL.md` — how work is done
4. `TRACKER.md` — current lanes and the next item
5. `PLAN.md` — phases and proof for each
6. `adr/` — why, not what

Do not put implementation notes in AGENTS.md. Put them in the tracker or an ADR.
